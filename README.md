# ORBITA

Космічна кав'ярня. Next.js 14 + Tailwind + Framer Motion + Lenis.

## Локально
    npm install
    npm run dev

## Деплой на GitHub Pages
1. Створи порожній репозиторій на github.com
2. Виконай:
       git init && git add . && git commit -m "init"
       git branch -M main
       git remote add origin https://github.com/ТВІЙ_НІК/НАЗВА.git
       git push -u origin main
3. Settings → Pages → Source: **GitHub Actions**
4. Дочекайся зеленого білда у вкладці Actions.
   Сайт: https://ТВІЙ_НІК.github.io/НАЗВА/
